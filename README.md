# 🥃 Casa do Gole

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso Técnico em Informática.

## 📖 Sobre

A Casa do Gole é uma plataforma web criada para representar uma destilaria fictícia especializada na produção de bebidas artesanais.

O sistema foi desenvolvido com foco em experiência do usuário, navegação intuitiva e organização de conteúdo.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- PHP

## ⚙ Funcionalidades

- Página Inicial
- Catálogo de Produtos
- Login
- Cadastro de Usuário
- Carrinho de Compras
- Página de Contato
- Navegação Responsiva
